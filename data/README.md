

# Data

`raw/hotel_bookings.csv` is the original Kaggle file: [Hotel booking demand](https://www.kaggle.com/datasets/jessemostipak/hotel-booking-demand) (Antonio, Almeida & Nunes; CC BY 4.0).

**Never edit it.** Notebooks read it and work on a copy in memory. Anything derived goes in `interim/` or `processed/` (git-ignored).
